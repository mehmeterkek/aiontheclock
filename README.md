# AI on the Clock

The published site for [aiontheclock.mehmeterkek.com](https://aiontheclock.mehmeterkek.com).

**Nothing in this repository is written by hand.** Every page here is generated
by the CMS and pushed in a single commit. Editing a file directly will work
until the next publish, which will overwrite it without asking.

To change something, change it in the CMS and publish again.

`.published.json` lists the files the last publish wrote. It is how publishing
knows what it is allowed to delete, so leave it alone.
